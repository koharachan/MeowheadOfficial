# 地球贴图（public/img/globe）

由 `site/scripts/build-globe.py` 生成：**天地图卫星影像瓦片（img_w）→ Web Mercator 拼图 → 等距圆柱（equirectangular）重投影**。

| 文件 | 尺寸 | 体积 | 数据源 | 用途 |
| --- | --- | ---: | --- | --- |
| `earth-2048.webp` | 2048×1024 | 161.9 KB | z=4（256 张） | **默认球体贴图**（q82，macOS/Android 全机型无压力） |
| `earth-4096.webp` | 4096×2048 | 556.4 KB | z=5（1024 张） | 可选高清版，镜头要推近时用（显存约 32MB） |
| `earth-1024.webp` | 1024×512 | 47.7 KB | 由以上降采样 | 低端机 / 首屏过渡 / 加载占位 |
| `earth-1024@preview.png` | 1024×512 | 404.3 KB | — | 肉眼检查用，**可不入库** |
| `earth-lqip.webp` | 128×64 | 1.4 KB | 由 2048 降采样 | 贴图加载前的占位（先铺一层，避免黑屏一闪） |

## 天地图瓦片权限结论（实测）

- 瓦片地址：`https://t{h}.tianditu.gov.cn/DataServer?T=img_w&x={x}&y={y}&l={z}&tk=<KEY>`（`t0`–`t7` 轮询）
- **必须带「浏览器 UA」**：不带 UA（curl 默认 / python-urllib 默认）返回
  `HTTP 403 {"code":301012,"msg":"权限类型错误","resolve":"Key权限类型为:浏览器端，请使用浏览器访问！"}`。
  带上 `Mozilla/5.0 … Chrome/131` 之类的 UA 后立刻 200 + 256×256 JPEG。
- **Referer 不是必须的**（实测带 / 不带 `https://maomaotou.tech/` 都 200）；脚本里仍然带上以求稳。
- `T=img_w` 是卫星影像，`T=vec_w` 是矢量底图（未使用）。
- 这个 Key 是浏览器端 Key，**只适合前端展示**；这张贴图是离线预生成的静态资源，线上不请求瓦片。

## 坐标约定

- **经度**：x=0 对应 **293.56°E（= 66.44°W）**，x=W/2 对应 **113.56°E（韶关）**，x=W 又回到 293.56°E。
  也就是把球体初始朝向转了 113.56°，让中国正对镜头；向东为 +x。
- **纬度**：标准 equirectangular，覆盖 **-90°…+90°**（v=0 在北极为 90°）。
  墨卡托原始数据只到 ±85.05°，两条边之外用边缘行填充（表现为南北极的冰盖色带）。
  > 如果要在 shader 里自己映射 ±85°，跑 `--lat-range 85` 重新生成即可；但用 `THREE.SphereGeometry` + `MeshStandardMaterial({ map })` 时**必须用默认的 -90…90 版本**，否则经纬度会整体错位。
- 贴图是 sRGB 彩色图，three.js 里记得 `texture.colorSpace = THREE.SRGBColorSpace`。

## 分辨率说明（重要）

| 贴图 | 赤道分辨率 | 韶关市区（约 1° 跨度） |
| --- | ---: | ---: |
| earth-1024 | 2.8 px/° | ~3 px |
| earth-2048 | 5.7 px/° | ~6 px |
| earth-4096 | 11.4 px/° | ~11 px |
| 天地图 z=8 瓦片 | ~910 px/° | 256px 瓦片约 0.28°/张 |

**这张全球贴图只适合「从太空看地球 → 放大到省级」**。再往城市级推近一定会糊，
建议在镜头拉近到 ~2 个屏幕高度以内时，切换到天地图 z=8/z=10 的瓦片或一张韶关局部底图。

## 处理链

1. 瓦片下载（缓存于 `/home/koharachan/assetwork/tiles/z{z}/`，z=5 共 1024 张）→ 拼成 `256·2^z` 见方的墨卡托底图；
2. numpy 条带式双线性重投影 → 等距圆柱；
3. 调色：饱和度 ×0.84、对比度 ×1.05、亮度 ×1.07（降饱和 + 提对比，让球体在奶白背景上更像实体；**不锐化**）；
4. WebP q82；1024 由主版本 Lanczos 降采样。

## 肉眼评价

- earth-4096：中国东部、日本、台湾、菲律宾、越南海岸线清晰；earth-2048 为省市级够用。
- 拼接缝：没有可见硬缝（同源同期瓦片，色调整体一致）。
- 云层：青藏高原、东南亚一带有明显云带，属于卫星影像本身，未处理。
- 海洋几乎纯黑（天地图低层影像的海洋就是深色），和奶白背景对比强，适合做「悬浮球体」。
- 南北极是纯白冰盖色带（见上面 ±85 说明）。

## 重新生成

```bash
python3 site/scripts/build-globe.py                          # earth-2048（z=4，默认 113.56°E 居中）
python3 site/scripts/build-globe.py --zoom 5 --width 4096    # earth-4096（z=5，约 20 秒，首次下载 1024 张瓦片）
python3 site/scripts/build-globe.py --lon 113.56 --lat-range 85
```

脚本复用瓦片缓存，重复跑 4–20 秒。
